## Что за система

Модель для двух проектов сразу: `ERC3_AI_Agent` (общий у Лоры со Стивом) и
`money_alert_ai` (Стив).

## Где лежит доступ

Переменная `OPENAI_API_KEY`, значение — в `.env` соответствующего проекта. Имена
переменных перечислены в `.env.example` каждого репозитория, значений там нет.

Проверять существование, не показывая:

```sh
grep -q '^OPENAI_API_KEY=.\+' .env && echo есть
```

## Один ключ на два проекта

Главное, что стоит помнить: проекты делят один ключ, а нагрузка у них разная. Полный
прогон ERC3 — 106 задач, порядка $5 за раз. `money_alert_ai` ходит понемногу, но по
расписанию.

Отсюда: **ночной прогон соревнования может выесть лимит, и утренний отчёт бота молча не
выйдет.** Если бот «пропустил публикацию» — сначала смотреть, что происходило с ключом,
и только потом лезть в код бота.

## Отдельно: ключ соревнования

У ERC3 есть **второй** ключ, свой собственный, к API самого соревнования. Он выдаётся
по регистрации на их сайте по адресу электронной почты и к OpenAI отношения не имеет.
Не путать: «агент не работает» здесь два разных диагноза.

## Грабли

- 429 от модели и 401 от API соревнования выглядят в логе прогона одинаково безлико.
  Смотреть, чей именно это ответ, — иначе чинится не то
- Ключ, вставленный в код «на минутку», уезжает в публичный репозиторий навсегда
