# MEMORY

Индекс памяти Альфреда. Одна строка на заметку, содержимое — в отдельных файлах.
Читается в начале каждого запуска.

Это **индекс, а не память**: не пиши сюда содержимое заметок. Строка — ссылка плюс
короткий крючок, по которому понятно, стоит ли открывать файл.

Секретов ни здесь, ни в заметках не бывает — только где лежит и как получить.

## Доступы

Карта по системам — `access/`, один файл на систему (правила заметки — в
[`access/README.md`](access/README.md)).

- [GitHub](access/github.md) — токен `gh` и секреты Actions; единственная система,
  которой пользуются все проекты, поэтому ротация задевает всех сразу
- [Anthropic API](access/anthropic-api.md) — циклы `anima` и `anima_sdk`. Сначала
  проверить, не работает ли всё по подписке: тогда ключ не нужен вообще
- [OpenAI API](access/openai-api.md) — `ERC3_AI_Agent` и `money_alert_ai` делят один
  ключ: ночной прогон соревнования может выесть лимит, и утренний отчёт не выйдет
- [Telegram Bot API](access/telegram-bot.md) — токена мало, бот должен быть админом в
  канале; для отладки отдельный бот и отдельный канал
- [Робот Go2 (сеть)](access/go2-robot-network.md) — доступ без ключа вообще: два
  сетевых режима. В AP-режиме ноутбук сидит без интернета, и это выглядит как
  «отвалились все ключи»

## Журнал
