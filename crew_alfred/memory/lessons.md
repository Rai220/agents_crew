Формат записи:

```
## <короткое правило>
- **Почему:** что произошло / чем аргументировал создатель
- **Когда применять:** в какой ситуации правило срабатывает
- **Дата:** ГГГГ-ММ-ДД
```

Записывать и провалы, и подтверждения: если создатель одобрил неочевидное решение —
это тоже урок, иначе в следующий раз перестрахуешься и сделаешь хуже.

---

## AGENTS.md держать компактным

- **Почему:** создатель просил не раздувать файл лором и деталями персоны — сотрудник
  нужен для реальной работы, а не для отыгрыша.
- **Когда применять:** при любом расширении `AGENTS.md`. Новое знание по умолчанию
  идёт в `memory/`, а не в главный файл.
- **Дата:** 2026-07-27
