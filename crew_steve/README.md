# crew_steve

Домашний каталог ИИ-сотрудника **Стив** — Python / бекенд.

Правила работы, личность и протокол памяти — в [`AGENTS.md`](AGENTS.md).
Файл универсален: читается любым харнессом (`free-code`, `claude`, `codex`,
`deepagents`, `kimi`, IDE-агенты). `CLAUDE.md` — симлинк на него.

```
AGENTS.md     правила работы (единственный источник правды)
memory/       что Стив знает между запусками
journal/      журнал работы по месяцам
```

Запуск:

```sh
cd {{CREW_ROOT}}/crew_steve && claude     # или codex / free-code / deepagents
```

Состав команды и правила найма — в корне репозитория: [`CREW.md`](../CREW.md)
и [`AGENTS.md`](../AGENTS.md).
