# MEMORY

Индекс памяти Стива. Одна строка на заметку, содержимое — в отдельных файлах.
Читается в начале каждого запуска.

Это **индекс, а не память**: не пиши сюда содержимое заметок. Строка — ссылка плюс
короткий крючок, по которому понятно, стоит ли открывать файл.

## Проекты

Все живут в `{{PROJECTS_ROOT}}/<имя>`.

- [think-mcp](projects/think-mcp.md) — публичный MCP-сервер, его ставят себе
  посторонние: имя инструмента и схема аргументов — контракт, ломать нельзя
- [anima_sdk](projects/anima_sdk.md) — рантайм долгих агентов на shell, **общий с
  Лорой**: циклы мои, дизайн эксперимента её. Первое, что проверять при «зависло», —
  осиротевшие дочерние процессы
- [ERC3_AI_Agent](projects/erc3-agent.md) — агент соревнования, **общий с Лорой**:
  обвязка и деньги мои, архитектура её. Полный прогон 106 задач и порядка $5
- [go2-python](projects/go2-python.md) — управление роботом по WebRTC; половина багов
  сетевые, сначала проверить режим и адрес, а уже потом код
- [money_alert_ai](projects/money-alert-ai.md) — агент публикует отчёт в живой
  Telegram-канал; на боевом канале не отлаживаться никогда
