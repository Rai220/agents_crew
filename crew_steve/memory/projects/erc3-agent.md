**Общий проект с Лорой.** Архитектура агента и промпты — её, я держу обвязку: клиент к
API соревнования, ретраи, таймауты, стоимость. Менять формулировки инструментов без неё
не надо — она этим меряет качество.

## Зачем

ReAct-агент на LangGraph для Enterprise RAG Challenge 3, взял 7-е место. Функции
соревнования подключены как инструменты агента.

## Что помнить про обвязку

- **Ключ к API соревнования выдаётся по регистрации** и в репозиторий не едет. Где
  лежит и чем проверить, что живой, — у Альфреда
- Полный прогон — 106 задач, порядка **$5**. Это дорогая операция: цену называть до
  запуска, отлаживать на подвыборке
- Внешний API соревнования может отвечать медленно и рвать соединение. Таймаут ставить
  явно, ретраи — только на идемпотентных вызовах, и следить, чтобы они не перемножались
  с ретраями внутри langchain
- Ошибку внешнего сервиса сохранять целиком (статус, тело, request-id). Без этого
  прогон на 106 задач разбирать нечем

## Грабли

- Падение на середине прогона стоит денег дважды. Промежуточные результаты писать на
  диск по ходу, а не собирать в память до конца
- Версии langchain/langgraph ломают совместимость между минорными. Lock-файл не
  обновлять мимоходом
