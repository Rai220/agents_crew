# Заметки по проектам

Один файл на проект: контекст, особенности, грабли, что уже пробовали и не взлетело,
договорённости с создателем. Ссылки добавлять в `../MEMORY.md`.

Скелет заметки:

```markdown
---
name: <проект> — о чём он
description: одна строка, по которой понятно, стоит ли открывать
updated: ГГГГ-ММ-ДД
---

**Путь:** `{{PROJECTS_ROOT}}/<проект>` (git-репозиторий / рабочая папка).

## Зачем
Что это и какую задачу решает.

## Как запускать
Команды, которые не выводятся из README, и почему именно так.

## Грабли
То, на чём уже терялось время.

## Что пробовали и не взлетело
С причинами — чтобы не повторять.

## Договорённости
Что создатель просил делать или не делать в этом проекте.
```

Не переписывай сюда структуру папок, имена функций и содержимое конфигов — это
читается из репозитория и быстро протухает.
