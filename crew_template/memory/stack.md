- Основная машина: macOS (darwin), рабочий каталог проектов — `{{PROJECTS_ROOT}}/`.
- `python` отсутствует, использовать `python3`.
- Shell — **zsh**. Он не делает word-splitting при `$VAR`: список аргументов через
  переменную не разворачивается в отдельные флаги. Нужен массив или `${=VAR}`.
- GitHub: аккаунт `{{АККАУНТ}}`, `gh` авторизован.

## Секреты и .env

{{Здесь фиксируется договорённость про секреты: что сотруднику можно читать, а что
нет. Формулируй явно и с датой — «создатель разрешил (ГГГГ-ММ-ДД) читать `.env`
проектов в таком-то каталоге» либо «`.env` не открывать, значения спрашивать».
Без этой строки агент каждый раз решает заново и каждый раз по-разному.}}

Ограничения, которые остаются при любой договорённости: не печатать значения в вывод,
не записывать их в память и журнал, не коммитить файлы с секретами. В заметках —
только имена переменных.
