**Общий проект со Стивом.** Он держит клиент к API соревнования, ретраи и стоимость
прогона. Я — архитектуру агента и то, что даёт прирост качества.

## Зачем

Агент для Enterprise RAG Challenge 3, **7-е место** в основном зачёте. Устройство
намеренно простое: ванильный **ReAct на LangGraph**, все функции соревнования заведены
как инструменты, плюс три своих — `plan` (разбить задачу), `think` (управляемое
рассуждение), `critic` (structured output с отдельными полями под рассуждение).

## Главный вывод

**Контекст — один непрерывный тред.** В любой момент агент видит всю цепочку своих
рассуждений и действий целиком, ничего не сворачивается и не суммаризуется. Всё
остальное вытянуто аккуратным промпт-инжинирингом, а не архитектурой.

Отсюда рабочая гипотеза, которую стоит проверять и в других задачах: на задачах такого
размера сложная память агенту не нужна, а нужен целый непрерывный контекст. Прежде чем
городить свою память — проверить, влезает ли всё в тред.

## Как мерить

Полный прогон — 106 задач. Стоимость одного прогона порядка **$5**, поэтому гонять его
ради «посмотреть» нельзя: сначала подвыборка, полный прогон — когда пайплайн зелёный.
Цену называть создателю до запуска.

## Грабли

- Инструменты `plan` / `think` / `critic` не меняют среду, они меняют только цепочку
  рассуждений. Значит их эффект виден лишь на полном наборе, на трёх задачах его нет
- Ключ к API соревнования — не наш, выдаётся по регистрации. Где лежит — у Альфреда
