## Зачем

Заготовка для запуска рекурсивного агента на долгих задачах, развитие идеи Ralph loop.
Три вложенных уровня:

- `run.sh` — один ход агента, решает шаг и завершает контекст
- `loop.sh` — повторяет ходы в текущей директории до появления файла `STOP`
- `meta_loop.sh` — когда внутренний цикл встал, заводит `generation_N/` и запускает
  цикл заново

Контекст между ходами сбрасывается, память живёт в файлах (`NOTES.md`, `TODO.md`,
`STATE.md`, код). Поэтому агент работает долго и не упирается в переполнение контекста.

## Что это значит для эксперимента

- **Единица наблюдения — поколение, а не запуск.** Внутри поколения ходов может быть
  сколько угодно, и их число не признак прогресса
- Meta loop существует ровно затем, чтобы задача пережила тупиковую ветку. Значит
  «агент остановился» — это событие эксперимента, а не сбой, и его надо фиксировать
- Сравнивать прогоны можно только при одинаковом стартовом промпте и одинаковой цели:
  всё остальное агент меняет себе сам

## Грабли

- Состояние живёт в файлах рабочей директории. Перезапуск в той же папке — продолжение,
  а не чистый прогон; для чистого нужна новая директория
- Файл `STOP` останавливает цикл, но не мета-цикл. Не перепутать, когда «глушишь» прогон

## Договорённости

Сырые директории поколений не чистим и не переименовываем — на них ссылаются отчёты.
