## Зачем

Вопрос исследования: если модель на обучении видит один и тот же пример решённым верно
и неверно, какой вариант она оставит себе. Учим трансформеры от 3.5M до 1B параметров
с нуля, корпус синтетический — каждая задача входит ровно дважды, один раз правильно,
один раз испорченно.

## Метрика — доля по всей ложной поддержке, не попарное сравнение

Главная методическая находка, и она стоила переписывания выводов. Попарная метрика
(«ниже ли лосс у верного решения, чем у одного взятого неверного») **не нейтральна**:
если ошибка может принять N форм, модель, которая просто воспроизводит частоты обучения
и не предпочитает ничего, всё равно выигрывает попарное сравнение при любом N ≥ 2.
Любой эксперимент, который поднимает N, бесплатно поднимает и попарную точность.

Поэтому суммируем по всему семейству ложных строк:

```
share = P(correct) / (P(correct) + Σ P(false_i))
```

**Практическое следствие для меня:** прежде чем радоваться росту метрики, проверять, не
подрос ли он от размера ложного семейства. Нулевая гипотеза считается **под конкретный
корпус**, а не берётся из головы.
