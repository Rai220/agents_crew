# MEMORY

Индекс памяти Лоры. Одна строка на заметку, содержимое — в отдельных файлах.
Читается в начале каждого запуска.

Это **индекс, а не память**: не пиши сюда содержимое заметок. Строка — ссылка плюс
короткий крючок, по которому понятно, стоит ли открывать файл.

## Окружение

## Проекты

Все живут в `{{PROJECTS_ROOT}}/<имя>`.

- [compression-drives-truth](projects/compression-drives-truth.md) — трансформеры с
  нуля на корпусе с верной и испорченной версией каждой задачи; метрика — доля по всей
  ложной поддержке, попарная не нейтральна
- [anima](projects/anima.md) — прогоны автономного агента с одной целью; между
  поколениями нет памяти кроме файлов, сырые директории не редактируем
- [anima_sdk](projects/anima_sdk.md) — рантайм под эти прогоны, **общий со Стивом**:
  циклы его, дизайн эксперимента мой
- [korovany](projects/korovany.md) — одно ТЗ на все модели вслепую; бенчмарк без
  правильного ответа, промпт дословно один и тот же
- [ERC3_AI_Agent](projects/erc3-agent.md) — ReAct на LangGraph, 7-е место; **общий со
  Стивом**: архитектура моя, обвязка и деньги его
